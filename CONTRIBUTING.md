# Contributing to AI Security Audit

Thank you for your interest in improving AI application security!

## How to Contribute

- **Add New AI Attack Patterns**: Expand audit coverage for emerging generative models, multimodal interfaces, and agentic protocols.
- **Improve False-Positive Filters**: Refine heuristics and tests that prevent model hallucination from being flagged as true vulnerabilities.
- **Enhance Remediation Guidance**: Contribute robust, production-tested defensive code snippets for popular frameworks (LangChain, LlamaIndex, Vercel AI SDK, AutoGen, CrewAI).

## Submission Guidelines

1. Fork the repository and create a descriptive branch: `git checkout -b feature/new-audit-check`.
2. Ensure markdown formatting is clean and links are valid.
3. Provide rationale and evidence for any new vulnerability classes or verification steps.
4. Open a pull request against `main` with a clear explanation of changes.
