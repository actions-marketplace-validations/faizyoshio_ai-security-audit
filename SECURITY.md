## Reporting a Vulnerability

We prioritize the security of developers and AI systems. If you discover a security flaw or an issue within this audit framework, please follow responsible disclosure guidelines:

1. **Do not create a public GitHub issue.**
2. Send vulnerability details directly to the project maintainer via GitHub Private Security Advisories or contact **[faizyoshio](https://github.com/faizyoshio/)**.
3. Include clear steps to reproduce the issue, expected versus actual behavior, and an assessment of risk.

We will acknowledge receipt within 48 hours and work with you on a resolution before public release.
